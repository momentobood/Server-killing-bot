# ☢️ Server-killing-bot

Telegram-бот для экстренного управления сервером и аварийного реагирования, написанный на Python с использованием библиотеки **Aiogram 3**.

> **⚠️ ВНИМАНИЕ:** Проект содержит потенциально опасный обработчик `/destroy`, который в текущей реализации запускает команду удаления корневой файловой системы. Использование может привести к необратимой потере данных и повреждению операционной системы.

---

## 📋 Основные функции

- **🔒 Контроль доступа:** доступ к основным функциям ограничен указанным Telegram User ID.
- **⚡ Интерактивная панель:** управление через инлайн-клавиатуру.
- **📊 Панель статуса:** отображение состояния системы.
- **☢️ Экстренный снос:** интерфейс аварийного удаления системы.
- **📝 Логирование:** регистрация событий и ошибок.
- **⚙️ Асинхронная работа:** использование asyncio.

---

## ⚙️ Требования

- **Python** версии 3.10 или выше.
- **Aiogram** версии 3.x.
- Аккаунт Telegram.
- Токен Telegram-бота от BotFather.

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/momentobood/Server-killing-bot.git
cd Server-killing-bot
```

### 2. Установка зависимостей

```bash
pip install aiogram
```

### 3. Настройка конфигурации

Откройте файл `main.py` и укажите параметры:

```python
BOT_TOKEN = "ВАШ_ТОКЕН_ОТ_BOTFATHER"
ALLOWED_USER_ID = 123456789
```

- `BOT_TOKEN` — токен вашего Telegram-бота.
- `ALLOWED_USER_ID` — ваш Telegram User ID.

### 4. Запуск бота

```bash
python main.py
```

---

## 🛠️ Список команд

| Команда | Описание |
|---|---|
| `/start` | Запуск бота и отображение приветствия |
| `/help` | Вывод справочной информации |
| `/menu` | Открытие интерактивной панели |
| `/destroy` | Обработчик экстренного удаления системы |

---

## 🎛️ Панель управления

В боте предусмотрены следующие кнопки:

- ⚡ Панель статуса
- ⚠️ Экстренный снос
- ❌ Закрыть меню

**Примечание:** кнопка экстренного сноса в текущей версии только отображает сообщение подтверждения. Дополнительного подтверждения и запуска удаления через неё пока нет.
